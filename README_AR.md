# سورس WolFox — النسخة 5

الميزات: GPS + BLE.
اسم الحزمة: com.wolfox.gps.variant5
هذه نسخة سورس مستقلة بإعدادات وحفظ محلي منفصلين عن بقية النسخ.

أصل الكود: سورس WolFox-GPS-ColorRoles المرفق. مكونات K7 الإضافية استُعيدت من DEX بواسطة JADX 1.5.2، ثم صُححت وربطت بلوحة WolFox. النسخ 1 و4 لهما نفس مجموعة الميزات الأساسية؛ النسخ 3 و5 لهما نفس مجموعة BLE ومعرّفات وحفظ مستقلان.

ليست مطابقة ثنائية لملف K7 الأصلي: تغير معرّف التطبيق والواجهة، ومحرك GPS هو WolFox.
توجد فحوص ترخيص WolFox الأصلية، وفحوص ترخيص K7 الأصلية للأدوات الإضافية. لم تُستبدل بنتيجة نجاح أو ترخيص تجريبي. تحتاج خوادم الترخيص الأصلية ومفتاحًا صالحًا؛ نجاح البناء لا يثبت توفر الخدمات أو صلاحية المفتاح.

البناء: Java 17 + Android SDK 34 + Build Tools 34.0.0. شغّل bash gradlew :app:assembleRelease. الناتج يحتاج توقيع إصدارك.
مسار Linux المباشر موضح في README.md، وهو مسار التحقق المستخدم.

مكونات الكاميرا أو البلوتوث متصلة بزر داخل لوحة WolFox في النسخ التي تتضمنها. إعادة BLE داخل التطبيق ولا تبث إشارات لاسلكية.
لا تفعّل عدة نسخ في التطبيق المضيف نفسه في الوقت ذاته؛ عزل التخزين لا يمنع تعارض اعتراضات GPS.

راجع VALIDATION.json وBUILD-VALIDATION.log للنتائج الفعلية. لا يوجد اختبار هاتف أو Xposed/LSPatch أو خادم ترخيص فعلي في هذه الجلسة. الوثائق التاريخية تحت docs/ موروثة من المشروع الأصلي ولا تثبت اختبارات النسخة المعدلة.
