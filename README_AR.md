# WolFox GPS Module 3.1.1

موديول Android يعمل داخل التطبيق المضيف المصرح به `com.t2.AvailoHader` عبر LSPatch أو LSPosed. لا يطلب `SYSTEM_ALERT_WINDOW`؛ الأيقونة تُرسم داخل `Activity` المضيف، ولا تظهر عند تثبيت APK الموديول وحده.

المزايا المدمجة:

- تفعيل إجباري من واجهة WolFox المهيأة داخل الموديول قبل إتاحة الأداة.
- ربط الكود بالتثبيت وبصمة الجهاز، وحفظ الترخيص حتى تاريخ الانتهاء عند انقطاع الشبكة.
- أيقونة WolFox دائرية قابلة للسحب؛ إطارها أخضر عند تشغيل محاكاة الموقع وأحمر عند إيقافها، مع حفظ الموضع والحجم والشفافية وإعادة تركيبها عند الانتقال بين الشاشات.
- لوحة مختصرة تبدأ برأس يحمل الاسم وزر الإغلاق، ثم معاينة خريطة مستطيلة قابلة للتوسيع.
- إخفاء الأيقونة بتأكيد مستقل وإظهارها مجددًا بالضغط المطول في منتصف الشاشة.
- اعتراض LocationManager و`getCurrentLocation` وGoogle Fused وHuawei HMS وWebView وخصائص Location، مع إبقاء علامة الموقع التجريبي قابلة للكشف.
- تعرض اللوحة حالة المحاكاة بوضوح؛ لا يُجبر `isMock()` أو `isFromMockProvider()` على إرجاع `false`، ولا تُخفى المحاكاة عن التطبيق المضيف.
- طبقة توافق إضافية لـ AMap وBaidu وMapbox وقوائم نتائج Google/Huawei، مع عزل فشل كل مزود لمنع الكراش.
- لا يحتوي الموديول على هوك لاعتراض Google Play ولا يتدخل في فتح المتجر أو تحديث التطبيق المضيف.
- بحث أصلي داخل Android مع مهلة استجابة مؤكدة وبدائل متعددة، ويدعم العنوان والإحداثيات العربية واللاتينية وروابط مشاركة Google Maps وApple Maps وخرائط Android.
- مفضلة كاملة: إضافة وتعديل وحذف وبحث واستيراد/تصدير JSON.
- زر «خريطة» في كل مفضلة يفتح عرضًا داخليًا عند إحداثياتها، مع طبقات المخطط والقمر الصناعي والبحث والسحب والقرص للتكبير وأزرار +/− ونسخ الإحداثيات وإعادة التمركز. هذا العرض لا يغيّر الموقع المحفوظ ولا يبدأ المحاكاة؛ تحميل البلاطات يحتاج اتصال إنترنت.
- قسم اشتراك مستقل يعرض الحالة وتاريخ البداية والنهاية والمدة والأيام المتبقية وآخر تحقق، مع تحقق يدوي من الخادم.
- سجل للبحث والتفعيل والتشغيل والإيقاف وتغيير الموقع.
- إعدادات الدقة والسرعة والارتفاع وحجم الأيقونة والشفافية وسجل الترخيص.

## شفافية محاكاة الموقع

الموقع الذي ينشئه الموديول موسوم كموقع تجريبي: يستخدم `Location.setMock(true)` على Android 12 فأحدث، ويحاول وضع علامة النظام المكافئة على الإصدارات الأقدم. لا تُعطّل فحوص اكتشاف الموقع التجريبي. قد تختلف إتاحة العلامة القديمة بحسب إصدار Android، لذلك اختبر ذلك على الجهاز المستهدف. تذييل اللوحة يذكر أن المحاكاة فعالة وأن علامة `mock` ظاهرة.

## البناء على Linux

```bash
chmod +x build-local.sh
WOLFOX_UNSIGNED_ONLY=1 ANDROID_SDK_ROOT=/path/to/android-sdk ./build-local.sh
```

المتطلبات: Android Platform 34، Build Tools 34.0.0، Java 17. إذا لم يوجد `javac` يستخدم السكربت ECJ الموجود في بيئة التطوير.

الناتج غير الموقّع والمحاذى (يلزم دمجه عبر LSPatch أو توقيعه بمفتاحك قبل تثبيته مستقلًا):

`build/local/apk/WolFox_GPS_Module_v3.1.1_UNSIGNED_ALIGNED.apk`

## الدمج

استخدم APK الموديول في LSPatch Manager بوضع Embedded مع التطبيق الذي تملك حق اختباره، أو ثبته كموديول في LSPosed ثم فعّله للنطاق المطلوب وأعد تشغيل التطبيق. اللوحة لا تُظهر الميزات إلا بعد إدخال كود صحيح.

## اللوحة

ملفات لوحة Hostinger موجودة في `backend/`. ابدأ من `backend/README_DEPLOY_AR.txt`، واستورد `backend/sql/schema.sql` للتثبيت الجديد أو `backend/sql/migrate_v2_to_v3.sql` للترقية.

لتجهيز الخادم باستخدام الأدوات المحلية الموجودة وضبط صلاحيات Linux نفّذ:

```bash
sudo bash backend/root_local_setup.sh
```

لا ينزّل السكربت أدوات، ولا يضيف root إلى Android، ولا يخفيه.

استخدم هذا الموديول فقط مع التطبيقات والحسابات التي تملك تصريحًا لاختبارها.
