# سورس النسخ الأربع: Android وiOS

## الفصل بين الأنظمة
Android: khalid003600-png/supreme-telegram، فروع edition/android-{gps,gps-bluetooth,gps-upload-identifier,full}-20261019.
iOS: khalid003600-png/H، فروع sandbox/wolfox-variant-{gps,gps-bluetooth,gps-upload-identifier,full}-20261019.
ملف edition.json يثبت النسخة وفرع iOS المقابل. لكل APK معرّف حزمة مستقل. لا يُنقل Objective-C إلى Android ولا تُستخدم حزم Android كمعرّفات تطبيقات iOS.

## التصميم المشترك
مرجع iOS: WFReferenceDesign.inc وWolFoxProTheme.m من Full commit 578ee382a83e7b853a2787feb1fa07f04b23ff99.
ألوان Graphite/Cyan وخط Cairo المرخّص OFL مضمّن دون تنزيل وقت التشغيل، أزرار موحدة داكنة، RTL، وارتفاع لمس 48dp. خريطة قمر صناعي أو مختلط، مواقع محفوظة وتعديل وحذف من القسم الحالي، إعدادات واشتراك، وقسم حركة في النسخ الأربع.
هذه مطابقة لغة التصميم والأقسام؛ لم يُجرَ تحقق بصري على جهاز، وليست شهادة تطابق بكسلي بين النظامين.

## نطاق الوظائف
GPS: الموقع والخريطة والمحفوظات والحركة اليدوية والسرعة.
GPS + Bluetooth: ما سبق مع المسح وأداة iBeacon بمعرّف UUID وMajor/Minor.
GPS + الصور + المعرّف: GPS مع اختيار الصور وتصوير النظام ومعاينة ومشاركة صورة المعرض، وتوليد/حفظ UUID محلي للتجارب.
Full: الأدوات السابقة جميعًا.
تُحجب مداخل الأدوات غير المتاحة وفق EditionConfig حتى عند استدعائها برمجيًا.

Android لا يحتوي في هذه الإضافة على تغيير Android ID أو استبدال كاميرا تطبيق آخر. UUID المحلي لا يغيّر معرّف الترخيص أو الجهاز. بث Beacon ليس محاكاة اتصال GATT. وظائف حقن iOS الأصلية تختلف عن واجهات Android المذكورة. رفع الصور لخادم لم يُضف لعدم تحديد endpoint ومصادقة. مصدر Android موديول يحتاج بيئة تحميل متوافقة؛ تثبيت APK وحده لا يثبت عمل الحقن.

## تقليل الكراش على الروت والجيلبريك
Android: SafeUi يحرس مداخل اللوحة والأقسام من RuntimeException وLinkageError، ويرفض عرض واجهة على Activity مغلقة. بقيت فحوص الصلاحيات ودعم BLE وتفكيك المسح، والبث يتوقف بالإغلاق أو بعد 60 ثانية. الخط يرجع لخط النظام إذا لم يُحمّل. لا يُغيَّر معالج أخطاء التطبيق ولا تُبتلع أخطاء الذاكرة القاتلة.
iOS: منع إعادة تثبيت نفس hook فوق نفسه وحفظ المؤشر الأصلي، والتحقق من method/type encoding قبل التثبيت. هذه حماية محددة من تكرار الحقن؛ ليست معالجة لكل كراش أو لإشارات SIGSEGV أو تعارضات إضافات أخرى.
لا تتضمن التغييرات إخفاء الروت أو الجيلبريك أو تجاوز فحصهما. الأجهزة دون بيئة تحميل مناسبة تحتاج تشغيلًا مختلفًا، ولا يوجد ضمان للعمل على جميع الأجهزة.

## التحقق
نجح فحص Python الخاص بالتصميم وأدوات الجهاز محليًا. التجميع واختبارات Robolectric تُشغّل على GitHub لأن البيئة المحلية لا تحتوي Android SDK أو javac ولا تستطيع تنزيل Gradle. ملفات APK الناتجة عن هذا المسار غير موقعة للإصدار؛ يلزم توقيع إصدار حقيقي قبل التوزيع. فحص verify_safe_favorites_map.py في الأساس يتوقع اختصار اشتراك مباشر في اللوحة بينما الأساس يضعه بالإعدادات؛ لم يُستخدم كشهادة نجاح.

اختبار الأجهزة المطلوب: Android 12–16 مع/دون روت وبيئة التحميل، رفض الأذونات، غياب BLE advertising، فتح/إغلاق الأقسام وتدوير الشاشة، انتهاء الترخيص، معاينة الصور الكبيرة، إيقاف BLE، ومراجعة تخطيط 320dp. iOS يحتاج جهازًا متوافقًا مع Rootful/Rootless؛ نجاح CI لا يثبت التشغيل الفعلي.
