# WolFox GPS — دليل النسخة المحسّنة QA2

هذه نسخة تحسين ثانية للموديول المدمج `com.wolfox.gps`، مع الإبقاء على الإصدار الداخلي `3.1.1` ورقمه `313`. ملفات QA2 منفصلة عن التسليم الأول، ولم تُستبدل أرشيفات المستخدم أو المخرجات السابقة.

## ترتيب الأزرار والخط والإغلاق

صفحة البحث تستخدم أزرارًا رأسية منفصلة داخل محتوى قابل للتمرير، بدل صفوف أفقية ضيقة ومتداخلة. تتكيف الارتفاعات مع النص والخط المكبّر؛ حد لمس الأزرار العادية 48dp، وزر التزييف 54dp كحد أدنى لا كارتفاع يقص النص. حقل البحث وحده يبقى أحادي السطر لروابط الخرائط والإحداثيات.

هناك تغذية راجعة Ripple أصلية عند الضغط، وشكل ونص مختلفان عند التعطيل، وحد تركيز واضح. أزرار النتيجة غير الجاهزة لا تعمل قبل وجود نتيجة صالحة. لا يُستدل على حالة زر من لونه فقط؛ النص والتمكين الفعلي يحددانها أيضًا.

الخط العربي الأصلي المرفق محفوظ. عولجت إعادة تطبيق الثيم التي كانت قد تبدّل العناوين المتوسطة إلى الخط العادي، ورُفع النص الصغير إلى حد أدنى 13sp دون منع تكبير خط النظام.

**زر إغلاق نُقل إلى أسفل المحتوى، بعيدًا عن عنوان الصفحة** في اللوحة والبحث والتفعيل والاشتراك والإعدادات والمفضلة والسجل والخريطة. وظيفته إغلاق النافذة، وليست قتل عملية التطبيق. في الصفحات القابلة للتمرير يمكن الوصول إليه بالتمرير لأسفل؛ في نوافذ الخريطة والقوائم توجد له مساحة تذييل مستقلة.

## ألوان الأزرار

لكل وظيفة لون متسق بين الصفحات. في صفحة البحث تختلف ألوان جميع وظائفها الأساسية: البحث أزرق، اللصق سماوي، المسح رمادي، تحديد الموقع أخضر، الحفظ بنفسجي، الخرائط أخضر مزرق، النسخ نيلي، والإغلاق أحمر داكن. النص أبيض عالي التباين، بينما التعطيل يجعل السطح أكثر هدوءًا والنص مختلفًا.

المفضلة بنية ذهبية، الاشتراك أرجواني، موقعي أزرق داكن، الإعدادات رمادي فحمي، إخفاء الأيقونة بني، والتفعيل أخضر زمردي. تزييف الموقع أحمر وإيقافه بلون خمري مختلف. تكرار الوظيفة بين صفحتين يحافظ على لونها نفسه بدل تغيير اللون اعتباطيًا.

اختبارات الألوان تقيس تباين النص الأبيض لأزرار البحث بنسبة لا تقل عن **4.5:1**، وتتحقق من اختلاف ألوان وظائف البحث ومن تباين النص الثانوي على الأسطح المشتركة. هذا اختبار للألوان المحددة في الشيفرة، وليس ادعاء فحص بصري لكل شاشة على كل هاتف.

## الموقع المختار من البحث أو المفضلة

تعرض بطاقة اللوحة **اسم الموقع المختار وإحداثياته الحالية** باتجاه LTR للإحداثيات كي لا تنعكس العلامات أو ترتيب latitude/longitude في واجهة عربية. المعاينة الداخلية تبني رابطها من النموذج الحالي للموقع.

أُصلحت ثلاث نواقص في التخزين: اختزال الإحداثيات إلى float، عدم حفظ اسم الموقع، واعتبار `(0,0)` موقعًا غير موجود. التخزين الجديد يحفظ double والاسم، ويقرأ القيم القديمة ويهاجرها دون مسح بيانات المفضلة أو التفعيل. لا يُقبل موقع خارج الحدود أو NaN/Infinity.

البحث يحتفظ بنسخة ثابتة من النتيجة واسمها، ولا يقبل رجوع callback قديم بموقع سابق بعد تغيير الاستعلام. اختيار مفضلة يحفظ اسم المفضلة مع الإحداثيات. النسخ وفتح الخرائط يستخدمان تمثيل double الكامل، بينما بطاقة اللوحة تعرض سبع منازل عشرية مقروءة.

**استعراض المفضلة على الخريطة لا يشغّل GPS**: زر الاستعراض ينسخ الإحداثيات الأصلية للمفضلة فقط. أما زر «استخدم» في قائمة المفضلة والتأكيد في البحث/الخريطة فيحتفظان بسياسة تحديد وتشغيل المصدر القائمة، وبشرط الترخيص. لم تُلغَ بوابة التفعيل أو انتهاء الاشتراك.

## زر تزييف الموقع

يبقى زر **تزييف الموقع** صريحًا. يتحقق من الترخيص والموقع وبيئة hooks واستجابة المحرك قبل عرض النجاح. بعد النجاح يكون نصه **إيقاف التزييف**.

أصبحت نتيجة الضغط رسالة ثابتة في اللوحة، لا Toast يختفي سريعًا وحده؛ يُذكر سبب رفض التشغيل عند غياب الموقع أو بيئة التحميل. تبقى اللوحة نفسها مفتوحة، ويُعاد تمكين الزر، وتتحدث بطاقة الحالة دون إعادة تحميل معاينة الخريطة. الضغط الثاني السريع خلال 500ms لا يبدأ أو يوقف جلسة أخرى بطريق الخطأ. علامة Mock لا تُخفى.

## الأيقونة العائمة

الأيقونة مخفية افتراضيًا، ولا يعيد التفعيل أو onResume إنشاء طلب ظهور. تظهر بالضغط المطوّل **850ms في منتصف شاشة المضيف**، ثم تُفتح اللوحة بالنقر عليها. تُخفى من خيار إخفاء الأيقونة أو بالضغط المطوّل عليها ثم التأكيد. الطلب الصريح مرتبط بالعملية الحالية؛ بعد إغلاق العملية وفتحها يلزم طلب جديد.

للمضيف المصرّح به:

```java
com.wolfox.gps.DirectBootstrap.showControls(activity);
com.wolfox.gps.DirectBootstrap.hideControls(activity);
```

لا توجد صلاحية SYSTEM_ALERT_WINDOW؛ الأيقونة داخل شاشة المضيف فقط، وليست فوق بقية التطبيقات. لا يوجد Launcher Activity لتطبيق مستقل.

## فعالية التغليف وحدوده

التغليف الحالي هو **تشويش أسماء R8** وتوقيع APK والتحقق من عقود DEX والتحميل؛ ليس تشفير DEX ولا حماية غير قابلة للفك. أصول HTML والخطوط والرمز تبقى ملفات قابلة للقراءة داخل APK.

تظل نقاط WolFoxHook وDirectBootstrap وواجهات JavaScript اللازمة بأسمائها الصحيحة. API Xposed اعتماد تجميع فقط، ولا تُعبَّأ فئات إطار Xposed أو stubs داخل APK. mapping الخاص ومفاتيح التوقيع والملفات المحلية وCI ليست ضمن الملفات المسلّمة.

APK موقّع **بمفتاح اختبار جديد لهذه النسخة** لا بمفتاح إصدار المستخدم الأصلي. لا يقبل Android تحديث حزمة مثبّتة بنفس الاسم بشهادة مختلفة. لبناء تحديث مطابق استخدم مفتاح الإصدار الأصلي عبر متغيرات التوقيع الخاصة؛ لا تُحذف بيانات التطبيق تلقائيًا ولا تحفظ مفاتيح التوقيع في المصدر.

## المتطلبات والبناء والتحقق

المصدر يضم Gradle Wrapper وملفات البناء والقواعد والأصول والاختبارات وسكربت تحقق موحد. يتطلب Java 17 وAndroid SDK 34 وBuild Tools 34.0.0. Gradle يتولى تنزيل تبعيات التجميع والاختبارات الرسمية. الخطوط والأيقونة والخريطة من مصادر المستخدم موجودة في المصدر وAPK.

التشغيل بدون خيارات المطوّر ممكن لأن الموديول لا يستخدم TestProvider. **التشغيل بدون روت يتطلب بيئة تحميل hooks متوافقة تعمل دون روت داخل التطبيق المصرّح به**؛ APK الموديول وحده لا ينشئها ولا يغيّر GPS للنظام أو كل التطبيقات. لم تُجهّز أو تُعدّل حزمة المضيف، ولم يُوسّع نطاق المصدر.

للبناء المحلي والفحص الموسّع باستخدام Xposed API الرسمي:

```bash
export JAVA_HOME=/path/to/java17
export ANDROID_SDK_ROOT=/path/to/android-sdk
export ANDROID_BUILD_TOOLS="$ANDROID_SDK_ROOT/build-tools/34.0.0"
export XPOSED_API_JAR=/path/to/official/xposed-api-82.jar
export WOLFOX_ALLOW_TEST_KEYSTORE=1  # اختبار فقط
bash scripts/verify-qa.sh
```

`XPOSED_API_JAR` اختياري لمسار البناء المحلي؛ عند غيابه تُستخدم stubs للتجميع فقط. **تسليم QA2 بُني مقابل API الرسمي مباشرة في javac وR8**. مسار Gradle يستخدم compileOnly الرسمي أيضًا. لا تُنزّل أو تُنفّذ أدوات تجميع مجهولة.

بيئة تحميل متوافقة وترخيص صالح واتصال لخادم التفعيل ولموارد الخريطة شروط تشغيل فعلية خارج اختبار المصدر. نتائج الاختبارات التفصيلية وحدود فحص الجهاز موثّقة في `QA2_VALIDATION_AR.md`.
