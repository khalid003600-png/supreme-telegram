# نتائج التحقق — WolFox GPS QA2

## النتيجة النهائية

نجح السكربت الموحد `scripts/verify-qa.sh` على المصدر النهائي بعد آخر تعديل لتمرير نافذتَي التفعيل والاشتراك. يشغّل Gradle tests وLint، ثم ثمانية حواجز مصدر، والبناء المحلي عبر API الرسمي، وفحص APK المحمي، وفحص عقد التغليف الموسع.

**45 اختبارًا ناجحًا؛ صفر failures، صفر errors، صفر skipped.** نتيجة Android Lint: **0 errors، 46 warnings**. لم تُعطّل Lint أو تُغطَّ جميع التحذيرات بقواعد تجاهل.

هذا يثبت سلامة البناء والعقود والاختبارات المحلية المحددة، ولا يثبت خلو جميع الأجهزة والبيئات من الأخطاء.

## العرض الصحيح للموقع

ثبت فقد الدقة والاسم في تخزين الإصدار السابق: إحداثيات float وغياب last_label واستبعاد `(0,0)`. إصلاح QA2 يستخدم `last_lat_bits` و`last_lng_bits` و`last_label` ويهاجر القيم القديمة. التحقق يرفض NaN/Infinity وخارج حدود الكرة الأرضية، ولا يعتبر بيانات تالفة موقعًا صالحًا.

المفضلة والبحث يحتفظان باسم الموقع. بطاقة اللوحة تعرض الاسم وإحداثيات سبع منازل عشرية في اتجاه LTR. المعاينة تستخدم lat/lng للنموذج الصحيح بـDouble.toString. اختبار المعاينة يفحص الرابط ومدخلاته، **ولا يدّعي تحميل بلاطات حقيقية أو تحقق pin بصريًا على هاتف**.

خريطة استعراض المفضلة تنسخ إحداثيات المفضلة الأصلية مباشرة وتعود قبل evaluateJavascript/confirmSelection، فلا تدخل مسار تشغيل GPS من العرض للقراءة فقط.

## الخط والتباين والإغلاق

الحد الأدنى للنصوص الصغيرة 13sp، مع احترام fontScale وحفظ خط DIN العربي المرفق والعناوين المتوسطة. أزرار البحث مرتبة رأسيًا وارتفاعاتها مرنة، والأزرار المشتركة ذات Ripple وتمييز تعطيل وتركيز. اللون وظيفة متسقة بين الصفحات وليس قيمة عشوائية.

زر الإغلاق نُقل لأسفل المحتوى في ثماني واجهات، مع حفظ مستمعه ووسمه إن وجد. النوافذ الطويلة قابلة للتمرير؛ نافذة التفعيل والاشتراك أضيف لهما التمرير للوصول إلى الإغلاق السفلي مع الخط الكبير. الاختبار المباشر للإغلاق يثبت النقل أسفل عنوان قياسي وعدم تكراره وبقاء النقر؛ لا يزعم تجربة كل النافذات على كل لوحة مفاتيح.

## البناء والتغليف

- Java 17، Android SDK 34، Build Tools 34.0.0.
- هوية APK: `com.wolfox.gps`؛ versionName `3.1.1`؛ versionCode `313`؛ min SDK 21 وtarget SDK 34.
- البناء النهائي استخدم Xposed API 82 الرسمي في **javac وR8**، مع سجل `xposed_api_mode=official-api-jar`.
- R8 أعاد تسمية **198 فئة داخلية**. قاعدتا dontshrink/dontoptimize مقصودتان للحفاظ على السلوك؛ هذا تشويش أسماء، لا تشفير DEX ولا تقليل كامل للمنطق أو ضمان ضد الهندسة العكسية.
- WolFoxHook وواجهات DirectBootstrap العامة بقيت بأسمائها الصحيحة وتواقيعها في DEX.
- JavaScriptInterface وMapSearchBridge وسلسلة resolver callbacks محفوظة.
- توقيع APK v1/v2/v3 ناجح، ZIP سليم، Manifest الثنائي غير debuggable، وallowBackup/usesCleartextTraffic false.
- الأيقونة وHTML والخطوط تطابق بايتات المصدر. لا Xposed stub definitions أو source/class files أو signing keys أو mapping داخل APK.
- DEX QA2 يختلف عن تسليم QA1 ويحتوي وسوم feedback/selected name/coordinates/footer، ومفاتيح الموقع الجديدة؛ ليس مجرد إعادة توقيع للنسخة السابقة.

APK ليس تطبيق Launcher مستقلًا؛ الأيقونة العائمة تُضاف داخل المضيف المصرّح به ولا تستخدم SYSTEM_ALERT_WINDOW. الأذونات لم تُوسّع، وشروط التفعيل والانتهاء ونطاق المضيف لم تُلغَ.
